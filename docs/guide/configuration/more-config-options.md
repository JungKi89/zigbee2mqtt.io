# 추가 설정 옵션

## 네트워크 맵

```yaml
# 선택 사항: 네트워크 맵 옵션
map_options:
    graphviz:
        # 선택 사항: graphviz 네트워크 맵에 사용할 색상 (기본값: 아래 표시)
        colors:
            fill:
                enddevice: '#fff8ce'
                coordinator: '#e04e5d'
                router: '#4ea3e0'
            font:
                coordinator: '#ffffff'
                router: '#ffffff'
                enddevice: '#000000'
            line:
                active: '#009900'
                inactive: '#994444'
```
