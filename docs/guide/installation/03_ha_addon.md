# Home Assistant addon

::: warning 주의
Home Assistant는 64비트 아키텍처(aarch64 및 amd64)만 지원합니다. 즉, Sonoff iHost(32비트)나 구형 Raspberry Pi(armv7) 같은 하드웨어는 사용할 수 없습니다.
:::

::: warning 주의
Raspberry Pi를 사용 중이라면 최소 Raspberry Pi 4를 사용해야 합니다. Raspberry Pi 3에서 실행하면 리소스 부족으로 인한 불안정 현상이 발생할 수 있습니다.
:::

Home Assistant OS 또는 Supervised Home Assistant 인스턴스를 실행 중인 경우, addon을 통해 Zigbee2MQTT를 설치하는 것이 가장 쉬운 방법입니다. 설치 방법은 [여기](https://github.com/zigbee2mqtt/hassio-zigbee2mqtt#installation)에서 확인할 수 있습니다.
