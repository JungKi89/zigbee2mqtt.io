Busch-Jaeger 6735/6736/6737

Model6735/6736/6737
VendorBusch-Jaeger
DescriptionZigbee Light Link power supply/relay/dimmer/wall-switch
Exposeslight (state, brightness), action
Picture

Notes

페어링

  1. LED가 깜박이고 있다면 깜박임이 멈출 때까지 기다리세요 — 기기가 원하지 않는 모드에 있는 것입니다.
  2. 상단 행(모델 6735의 경우 유일한 행)의 두 버튼을 LED가 계속 켜질 때까지 누르세요. 처음에는 교대로 깜박이다가 두 LED 모두 계속 켜질 때까지 버튼을 누르고 있으세요. 그런 다음 버튼을 놓으세요. LED가 계속 켜져 있어야 합니다.
  3. 이제 두 버튼을 다시 짧게 누르세요. 약 1~2초 후 서서히 꺼지며, 브리지가 즉시 기기를 찾아야 합니다.

알려진 문제

4-gang 기기의 하단 행이 바인딩되지 않음

4-gang 기기 6737의 하단 행이 다른 행처럼 동작하지 않아 액션을 발생시키지 않는 경우가 있습니다 (관련 토론 #7009 참고). 원인은 아직 완전히 파악되지 않았으나, 4개의 엔드포인트를 모두 언바인딩한 후 하나씩 수동으로 다시 바인딩하면 해결할 수 있습니다:

Source EPDestinationDestination EPClusters
10Coordinator1LevelCtrl (전원 공급 장치 또는 배터리 작동 벽면 스위치에만 해당)
11Coordinator1LevelCtrl
12Coordinator1LevelCtrl
13Coordinator1LevelCtrl

*[EP]: Endpoint

단일 엔드포인트는 하나의 목적지에만 바인딩 가능

기본적으로 모든 바인딩은 기기가 Zigbee2MQTT를 통해 버튼 이벤트를 보고하도록 설정되어야 합니다 (디머/릴레이의 상단 행 제외). 커스텀 바인딩도 정의할 수 있지만, 각 소스 엔드포인트는 하나의 목적지 엔드포인트에만 바인딩될 수 있다는 점을 유의하세요. 엔드포인트(버튼 행에 해당)의 기본 바인딩을 변경하려면 다음 방법을 권장합니다:

  1. 특정 엔드포인트의 현재 목적지 언바인딩
  2. 바인딩 파트너를 위한 Zigbee 그룹 생성
  3. 스위치 엔드포인트를 Zigbee 그룹에 바인딩

단일 조명에만 바인딩하려는 경우에도 Zigbee 그룹을 사용해야 합니다! 이 방법으로 코디네이터에 명시적 바인딩이 없어도 Zigbee2MQTT가 버튼 이벤트를 계속 게시합니다.

릴레이가 조광 가능 조명으로 노출됨

6735/6736/6737 기기를 디머 대신 릴레이에 설치해도 여전히 조광 가능 조명으로 노출됩니다. Zigbee 수준에서 릴레이와 디머를 구별할 방법이 없기 때문입니다. Home Assistant를 사용하면서 밝기 기능을 노출하지 않으려면 설정 파일에서 구성할 수 있습니다:

‘0xd85devicemac’:
  filtered_attributes:
    - brightness
    - brightness_relay
  homeassistant:
    light_relay:
      brightness: false

배터리 작동 제어판의 중복 이벤트

배터리 작동 벽면 스위치가 중복된 action 이벤트를 전송할 수 있습니다. 이 경우 기기에 디바운싱을 설정할 수 있습니다:

‘0xd85devicemac’:
  debounce: 0.2
  debounce_ignore:
    - action:

버튼을 누를 때마다 약간의 지연이 생기지만, 환경에서 중복 이벤트가 발생하는 경우 이를 해결할 수 있습니다.

배터리 작동 제어판의 설정 깨우기가 매우 어려움

배터리 작동 기기는 전력 효율이 매우 높습니다. 버튼을 누른 후 거의 즉시 딥 슬립 상태로 들어갑니다. 따라서 새 설정을 전송하거나 바인딩을 변경하기가 매우 어려울 수 있습니다.

2행 및 4행 기기의 경우 다음 절차가 효과적인 것으로 입증되었습니다:

  1. 상단 행의 두 버튼을 LED가 계속 켜질 때까지 누르세요.
  2. 하단 행의 버튼을 누르는 동시에 Zigbee2MQTT를 통해 임의 행에 Unbind 요청을 전송하세요. 여러 번 시도가 필요할 수 있습니다.
  3. 중요: 기기 설정이 완료될 때까지 이 엔드포인트/행을 언바인딩 상태로 유지하세요!
  4. 필요에 따라 엔드포인트/바인딩을 설정하세요. 새 설정을 전송하려면 기기를 다시 깨워야 합니다. 하단 (언바인딩된) 행의 버튼을 누르면 약 2초간 기기가 깨어있게 됩니다.

단일 행 기기는 스위치 재설정 시 배터리를 정확한 순간에 다시 삽입해야 할 수 있습니다.

액션 값

이 기기는 페이로드에서 다음 action 값을 전송합니다:

왼쪽 버튼(길게 누름-놓기)오른쪽 버튼
off_row_1, brightness_step_down_row_1brightness_stop_row_1on_row_1, brightness_step_up_row_1
off_row_2, brightness_step_down_row_2brightness_stop_row_2on_row_2, brightness_step_up_row_2
off_row_3, brightness_step_down_row_3brightness_stop_row_3on_row_3, brightness_step_up_row_3
off_row_4, brightness_step_down_row_4brightness_stop_row_4on_row_4, brightness_step_up_row_4

버튼을 짧게 누르고 놓으면 해당 행의 off_row_X 또는 on_row_X 액션이 발생하고, 길게 누르면 약 1초 후 brightness_step_down_row_X/brightness_step_up_row_X 상태가 발생합니다. 길게 누른 후 버튼을 놓으면 왼쪽 또는 오른쪽 버튼 구분 없이 brightness_stop_row_X가 발생합니다.

기기 설정에 따라 모든 액션이 전송되지 않을 수 있습니다.

Options

How to use device type specific configuration

  • state_poll_interval: This device does not support state reporting so it is polled instead. The default poll interval is 60 seconds, set to -1 to disable. The value must be a number with a minimum value of -1

  • transition: Controls the transition time (in seconds) of on/off, brightness, color temperature (if applicable) and color (if applicable) changes. Defaults to 0 (no transition). The value must be a number with a minimum value of 0

  • state_action: State actions will also be published as 'action' when true (default false). The value must be true or false

  • simulated_brightness: Simulate a brightness value. If this device provides a brightness_move_up or brightness_move_down action it is possible to specify the update interval and delta. The action_brightness_delta indicates the delta for each interval. Example:

simulated_brightness:
  delta: 20 # delta per interval, default = 20
  interval: 200 # interval in milliseconds, default = 200

Exposes

Light (relay endpoint)

This light supports the following features: state, brightness.

  • state: To control the state publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"state_relay": "ON"}, {"state_relay": "OFF"} or {"state_relay": "TOGGLE"}. To read the state send a message to zigbee2mqtt/FRIENDLY_NAME/get with payload {"state_relay": ""}.

  • brightness: To control the brightness publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"brightness_relay": VALUE} where VALUE is a number between 0 and 254. To read the brightness send a message to zigbee2mqtt/FRIENDLY_NAME/get with payload {"brightness_relay": ""}.

On with timed off

When setting the state to ON, it might be possible to specify an automatic shutoff after a certain amount of time. To do this add an additional property on_time to the payload which is the time in seconds the state should remain on. Additionally an off_wait_time property can be added to the payload to specify the cooldown time in seconds when the light will not answer to other on with timed off commands. Support depends on the light firmware. Some devices might require both on_time and off_wait_time to work Examples : {"state" : "ON", "on_time": 300}, {"state" : "ON", "on_time": 300, "off_wait_time": 120}.

Moving/stepping

Instead of setting a value (e.g. brightness) directly it is also possible to:

  • move: this will automatically move the value over time, to stop send value stop or 0.
  • step: this will increment/decrement the current value by the given one.

The direction of move and step can be either up or down, provide a negative value to move/step down, a positive value to move/step up. To do this send a payload like below to zigbee2mqtt/FRIENDLY_NAME/set

NOTE: brightness move/step will stop at the minimum brightness and won't turn on the light when it's off. In this case use brightness_move_onoff/brightness_step_onoff

{
  "brightness_move": -40, // Starts moving brightness down at 40 units per second
  "brightness_move": 0, // Stop moving brightness
  "brightness_step": 40 // Increases brightness by 40
}

Action (enum)

Triggered action (e.g. a button click). Value can be found in the published state on the action property. It's not possible to read (/get) or write (/set) this value. The possible values are: off_row_1, on_row_1, brightness_step_down_row_1, brightness_step_up_row_1, brightness_stop_row_1, off_row_2, on_row_2, brightness_step_down_row_2, brightness_step_up_row_2, brightness_stop_row_2, off_row_3, on_row_3, brightness_step_down_row_3, brightness_step_up_row_3, brightness_stop_row_3, off_row_4, on_row_4, brightness_step_down_row_4, brightness_step_up_row_4, brightness_stop_row_4, recall_*_row_*.
