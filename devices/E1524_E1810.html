IKEA E1524/E1810

ModelE1524/E1810
VendorIKEA
DescriptionTRADFRI remote control
Exposesidentify, battery, action
Picture

Notes

페어링

코디네이터 가까이에서 CR2032 배터리 옆의 내부 버튼을 5초 이내에 4번 눌러 리모컨을 Zigbee2MQTT에 페어링하세요. 리모컨 (앞면의) 빨간 불빛이 몇 번 깜빡입니다.

문제 해결: 배터리 잔량이 없거나 메시지를 전혀 보내지 않는 경우

배터리를 몇 초 동안 빼뒀다가 Configure를 통해 재설정하는 것이 도움이 될 수 있습니다. Configure를 실행하기 직전에 기기의 버튼을 눌러 기기를 깨워 두세요.

문제 해결: OTA 요청에 응답하지 않는 기기

Device didn't respond to OTA request 오류를 해결하려면 업데이트를 시작하기 직전에 리모컨의 버튼을 눌러 기기를 깨워 보세요.

문제 해결: 버튼 누름으로 트리거된 자동화에서 예외 발생

리모컨의 'action' 속성으로 트리거되는 자동화가 'restart' 모드로 설정되지 않도록 하세요. 버튼 누름(예: arrow_left_click)과 릴리스(예: arrow_left_release) 이벤트가 모두 있으므로 트리거가 연속으로 두 번 실행될 수 있으며, 이로 인해 첫 번째 실행이 완료되기 전에 자동화가 취소될 수 있습니다.

바인딩

이 리모컨의 바인딩 기능은 펌웨어 버전에 따라 다릅니다:

  • < 2.3.014: 바인딩이 지원되지 않으므로 OTA 업데이트를 통해 바인딩 기능을 사용하세요.
  • 2.3.014 - 2.3.074: 그룹에만 바인딩 지원. 한 번에 1개의 그룹에만 바인딩할 수 있습니다. 기본적으로 이 리모컨은 기본 바인딩 그룹에 바인딩되어 있으므로 먼저 해제해야 합니다. zigbee2mqtt/bridge/request/device/unbind에 페이로드 {"from": "DEVICE_FRIENDLY_NAME", "to": "default_bind_group"}를 전송하여 해제할 수 있습니다. 명령을 전송하기 직전에 버튼을 눌러 기기를 깨우세요.
  • 2.3.075 - 2.3.080: 기기에만 바인딩 지원
  • 24.4.5: 기기 또는 그룹에 바인딩 지원

참고: MQTT 메시지나 프론트엔드를 통해 'bind' 명령을 전송하기 전에 리모컨의 버튼을 눌러 깨우세요. 그렇지 않으면 리모컨이 수신 상태가 아니어서 일반 '오류'와 함께 바인딩이 실패합니다.

그룹/전구에 바인딩하면 토글 및 밝기 버튼은 작동하지만, 씬/색온도는 펌웨어 버전에 따라 작동하지 않을 수 있습니다.

  • < 24.4.5:
    1. ID 65289인 그룹을 만들고(예: Trafri_scenes로 이름 지정) 리모컨으로 제어할 기기를 추가하세요.
    2. 생성한 그룹에 씬을 추가/저장하세요.
    3. 리모컨에서 왼쪽/오른쪽을 클릭하면 씬이 순서대로 호출됩니다(씬 동기화가 맞지 않으면 토글 버튼을 3초간 누르세요).
  • 24.4.5: 밝기와 씬/색을 제어하려면 LevelCtrl과 Scenes 클러스터를 기기나 그룹에 바인딩하세요(그룹의 경우 LevelCtrl만 지원됨).

토글 버튼

리모컨 중앙 버튼을 클릭하면 {"click": "toggle"}을 전송하고, 누르고 있으면 {"click": "toggle_hold"}도 함께 전송합니다. 버튼을 누르고 있을 때 toggle을 건너뛸 수 없습니다. 버튼을 놓아도 리모컨은 아무것도 전송하지 않습니다. 자세한 내용은 링크를 참조하세요.

OTA 업데이트 문제 해결

펌웨어 업데이트 실행에 문제가 있다면 다음을 시도해 보세요:

  1. Z2M에서 "Update firmware" 버튼을 클릭한 후 1~2초마다 리모컨의 아무 제어 버튼이나 클릭하세요.
  2. 리모컨이 계속 펌웨어 업데이트를 중단하면 새 배터리로 교체하고, 기기를 초기화해 보세요 (배터리 옆의 페어링 버튼을 5초 이내에 4번 누르기).

Options

How to use device type specific configuration

  • identify_timeout: Sets the duration of the identification procedure in seconds (i.e., how long the device would flash).The value ranges from 1 to 30 seconds (default: 3). The value must be a number with a minimum value of 1 and with a maximum value of 30

Exposes

Identify (enum)

Initiate device identification. This device is asleep by default.You may need to wake it up first before sending the identify command.. Value will not be published in the state. It's not possible to read (/get) this value. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"identify": NEW_VALUE}. The possible values are: identify.

Battery (numeric)

Remaining battery in %. Value can be found in the published state on the battery property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"battery": ""}. It's not possible to write (/set) this value. The minimal value is 0 and the maximum value is 100. The unit of this value is %.

Action (enum)

Triggered action (e.g. a button click). Value can be found in the published state on the action property. It's not possible to read (/get) or write (/set) this value. The possible values are: toggle, brightness_up_click, brightness_down_click, brightness_up_hold, brightness_up_release, brightness_down_hold, brightness_down_release, toggle_hold, arrow_left_click, arrow_left_hold, arrow_left_release, arrow_right_click, arrow_right_hold, arrow_right_release.
