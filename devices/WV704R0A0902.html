Schneider Electric WV704R0A0902

ModelWV704R0A0902
VendorSchneider Electric
DescriptionWiser radiator thermostat
Exposesclimate (occupied_heating_setpoint, local_temperature, running_state, pi_heating_demand), battery, voltage, keypad_lockout
Picture

Notes

기기 페어링/설치

TRV를 설치 모드로 전환하려면 캡을 + 방향으로 돌리면서 중앙 LED가 초록색으로 깜빡일 때까지 누릅니다. 기기가 네트워크 합류 준비가 되면:

  • 좌/우 LED가 빨간색/파란색으로 깜빡입니다.
  • 중앙 LED가 주황색으로 고정됩니다.

중앙 LED가 초록색으로 고정되면 TRV가 페어링되어 Zigbee 네트워크에 연결된 것입니다.

노란색으로 깜빡이는 경우, TRV가 페어링되지 않았거나 Zigbee 네트워크에 연결할 수 없습니다. Zigbee2MQTT가 실행 중이고 새 기기를 허용하고 있으면 밸브가 네트워크에 합류해야 합니다. 합류를 시도하기 전에 캡을 + 방향으로 3초간 돌리며 누를 필요가 있을 수 있습니다.

참고: TRV를 캘리브레이션하기 전까지 Zigbee2MQTT가 TRV를 올바르게 설정하지 못할 수 있습니다.

밸브가 인식되지 않으면 부스트 버튼을 양수 방향으로 돌려서 누릅니다. 빨간 불이 천천히 깜빡이기 시작합니다. 빨간 불이 깜빡이기를 멈추면 버튼을 놓습니다.

기기가 네트워크 페어링/합류에 실패하거나(red:yellow:blue 페어링 모드), 네트워크 ID/채널을 변경했거나, 다른 네트워크에 연결하거나, 중고 TRV를 구입한 경우, 공장 초기화를 수행하여 새로 시작할 수 있습니다.

라디에이터 서모스탯 초기화

라디에이터 서모스탯을 공장 초기화하려면 다음을 수행하세요:

  1. 중앙 LED가 빨간색으로 깜빡이기 시작할 때까지 라디에이터 서모스탯 캡을 ‘-’ 방향으로 돌리며 누릅니다.
  2. 3개 LED가 한 번씩 깜빡여 기기가 초기화 중임을 나타낼 때까지 캡을 ‘-’ 방향으로 계속 누릅니다.
  3. 초기화가 완료될 때까지 기다립니다. 최대 20초가 소요될 수 있습니다.
  4. 기기가 [깜빡임 ~ 고정 호박색 ~ 깜빡임]으로 돌아오면 초기화가 완료된 것입니다.

라디에이터 서모스탯 재캘리브레이션

라디에이터 서모스탯을 재캘리브레이션하려면 다음을 수행하세요:

  1. 먼저 라디에이터 서모스탯이 라디에이터에 단단히 고정되어 있는지 확인하세요.
  2. 그런 다음 빨간 불이 켜지며 밸브가 완전히 열릴 때까지 캡을 ‘+’ 방향으로 8초간 돌립니다.
  3. 캡을 놓습니다.
  4. 그런 다음 파란 불이 켜지며 밸브가 닫힐 때까지 캡을 ‘-’ 방향으로 2초간 돌립니다.
  5. 이를 통해 라디에이터 서모스탯이 닫혀 있어야 할 때 라디에이터 핀에 적절한 압력을 가하고 있는지 확인합니다.

일반 사용

밸브가 설정에 응답/확인하지 못하는 경우가 있습니다. 명령을 다시 전송하세요.

pi_heating_demand: local_temperature가 occupied_heating_setpoint에 가까워질수록 밸브 위치를 동적으로 변경하여 과열을 방지합니다.

값이 0보다 크면 TRV가 열을 요구하고 있음을 나타냅니다. 따라서 애플리케이션에서 이 값을 모니터링하고 0보다 클 때 열을 공급해야 합니다.

battery: 레벨은 2.2V (0%)에서 3.0V (100%) 범위의 전압에 해당합니다. 0%는 배터리 교체가 필요함을 나타내지만 밸브는 계속 작동합니다.

추가 보고 상태 속성

MOT (string)

모터 상태.

  • MOT 속성의 게시된 상태에서 값을 확인할 수 있습니다.
  • 가능한 값은 Stall, CloseValue이며, 다른 값도 가능하지만 작성 시점에는 알 수 없습니다. 모터가 작동 중일 때 변경되는 것으로 보입니다.
  • 이 값을 읽거나(/get) 쓸(/set) 수 없습니다.

boost (string)

마지막으로 알려진 트위스트 탑 부스트 상태.

  • 밸브가 일정 시간 후 자동으로 값을 0으로 전환하지 않으므로, 값을 사용하려면 설정/자동화 로직이 필요합니다. 예를 들어 Home Assistant에서는 expire_after 설정을 사용하여 이를 처리할 수 있습니다.
  • boost 속성의 게시된 상태에서 값을 확인할 수 있습니다.
  • 가능한 값: Up, Down.
  • 이 값을 읽거나(/get) 쓸(/set) 수 없습니다.

keypad_lockout

키패드 잠금, 즉 트위스트 탑 부스트 활성화/비활성화.

  • 키패드를 잠금 (즉, lock1)으로 설정하면 트위스트 탑 부스트 버튼이 비활성화되어 부팅 및 설치 모드가 방지됩니다. 기기는 여전히 초기화할 수 있지만, 초기화 후에도 키패드가 잠금 상태를 유지하는 것으로 보입니다 (?).

  • keypad_lockout 속성의 게시된 상태에서 값을 확인할 수 있습니다.

  • 가능한 값: unlock, lock1.

  • 쓰기:

    • zigbee2mqtt/FRIENDLY_NAME/set 토픽에 {"keypad_lockout": "VALUE"} 페이로드를 게시합니다. VALUE는 unlock 또는 lock1입니다.

  • 읽기:

    • zigbee2mqtt/FRIENDLY_NAME/get에 {"keypad_lockout": ""} 페이로드를 게시합니다.

ADC

알 수 없음 - 쉼표로 구분된 기기 매개변수 값으로 보입니다.

ALG

알 수 없음 - 쉼표로 구분된 기기 매개변수 값으로 보입니다.

Options

How to use device type specific configuration

  • thermostat_unit: Controls the temperature unit of the thermostat (default celsius). The value must be one of celsius, fahrenheit

Exposes

Climate

This climate device supports the following features: occupied_heating_setpoint, local_temperature, running_state, pi_heating_demand.

  • occupied_heating_setpoint: Temperature setpoint. To control publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"occupied_heating_setpoint": VALUE} where VALUE is the °C between 5 and 30. To read send a message to zigbee2mqtt/FRIENDLY_NAME/get with payload {"occupied_heating_setpoint": ""}.
  • pi_heating_demand: Position of the valve (= demanded heat) where 0% is fully closed and 100% is fully open. Writing (/set) this attribute is not possible. Reading (/get) this attribute is not possible.
  • local_temperature: Current temperature measured on the device (in °C). Reading (/get) this attribute is not possible.
  • running_state: The current running state. Possible values are: idle, heat. Reading (/get) this attribute is not possible.

Battery (numeric)

Remaining battery in %, can take up to 24 hours before reported. Value can be found in the published state on the battery property. It's not possible to read (/get) or write (/set) this value. The minimal value is 0 and the maximum value is 100. The unit of this value is %.

Voltage (numeric)

Voltage of the battery in millivolts. Value can be found in the published state on the voltage property. It's not possible to read (/get) or write (/set) this value. The unit of this value is mV.

Keypad lockout (enum)

Enables/disables physical input on the device. Value can be found in the published state on the keypad_lockout property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"keypad_lockout": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"keypad_lockout": NEW_VALUE}. The possible values are: unlock, lock1, lock2.
