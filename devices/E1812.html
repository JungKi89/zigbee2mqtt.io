IKEA E1812

ModelE1812
VendorIKEA
DescriptionTRADFRI shortcut button
Exposesidentify, battery, action
Picture

Notes

관련 기기

  • TRADFRI on/off switch
  • TRADFRI open/close remote

정보

  • FCC - 방출, 분해, 사용 설명서
  • CSA IoT - Zigbee 인증
  • Silabs 칩셋 기반

배터리

CR2032 배터리(3V) 1개를 사용합니다.

이 기기는 활발하게 사용되지 않을 때 에너지 절약을 위해 슬립 상태가 됩니다.
슬립 상태에서는 어떤 Z2M 명령에도 응답하지 않습니다.
바인딩 시도 등과 같이 인터랙션이 필요할 때는 버튼을 반복해서 눌러 깨어 있는 상태를 유지하세요.

페어링

하단 커버를 돌려서 제거하면 페어링 버튼이 나타납니다.
페어링 버튼을 4번 눌러 공장 초기화하고 페어링을 시작하세요.
연결될 때까지 빨간 불빛이 깜빡이며 맥박처럼 깜빡입니다.

Touchlink

이 버튼은 Zigbee 네트워크 없이 바인딩을 설정하기 위해 Touchlink를 사용합니다.
활성화하려면 제어하려는 기기 가까이에 가져간 다음 페어링 버튼을 10초간 누르고 있으세요.
안타깝게도 초기 펌웨어에서는 Off 명령이 없어 거의 유용하지 않습니다. 또한 펌웨어 업데이트를 하면 이 기능이 완전히 제거됩니다.

바인딩

Zigbee 네트워크에 연결된 경우 이 리모컨은 기기나 그룹을 직접 제어할 수 있습니다.

초기 펌웨어에서는 여러 기기와 여러 그룹에 바인딩할 수 있습니다.
예를 들어 모든 명령을 활성화하려면 단일 클러스터 genOnOff를 바인딩하세요. 여러 클러스터를 바인딩하면 명령이 중복(스팸)됩니다!

최신 펌웨어에서는 여러 기기 또는 하나의 그룹에 바인딩할 수 있습니다.
기기를 제어하려면 필요한 모든 클러스터(genOnOff 및 genLevelCtrl)를 바인딩하세요.
그룹을 제어하려면 genBasic만 바인딩하고 코디네이터를 포함한 나머지 모든 것을 언바인딩하세요.

기기에 바인딩하면 해당 기기가 오프라인 상태가 될 때 리모컨이 네트워크에 스팸을 보내고 배터리가 빨리 소모될 수 있습니다. 이를 방지하려면 그룹에 바인딩하세요.

동작 매핑

최신 펌웨어는 더블 클릭 = off를 지원합니다.
이를 수용하기 위해 싱글 클릭에 눈에 띄는 0.6초 지연이 추가됩니다.

PressZ2M ActionBind Action
싱글onOn
더블offOff
세 번 이상Multiple off and onMultiple Off and On
길게brightness_move_up + brightness_stopMoveWithOnOff (Up, 83 units/s) + StopWithOnOff

구형 펌웨어에는 멀티 클릭이 없습니다.
이 버전은 디바운스 시간이 0.4초로 매우 길어서 자동화에서 설정조차 불가능합니다.
그러나 싱글 클릭은 즉시 전송된다는 장점이 있습니다.

PressZ2M ActionBind Action
싱글onOn
길게brightness_move_up + brightness_stopMoveWithOnOff (Up, 83 units/s) + StopWithOnOff

모든 버전에서 롱 프레스가 감지될 때까지 약 0.7초간 버튼을 눌러야 합니다.

  • v24.4.6, 날짜 20230308: 최신이자 유일한 업데이트

문제 해결

  1. 페어링 어려움, 동작 null
    • 코디네이터 업데이트
    • 불량 라우터(예: Telink Tuya, AwoX) 전원을 끄고 다시 페어링
    • 코디네이터를 통해 직접 페어링
    • 동글 코디네이터에 USB 2.0 연장 케이블 추가
  2. 페어링 후 배터리 null
    • 리모컨 전원을 껐다 켜고 퍼센트 새로 고침
  3. 배터리가 너무 빨리 소모됨, 동작 null, 리모컨 오프라인
    • 오프라인 기기에서 초기화 또는 언바인딩

OTA updates

This device supports OTA updates, for more information see OTA updates.

Options

How to use device type specific configuration

  • identify_timeout: Sets the duration of the identification procedure in seconds (i.e., how long the device would flash).The value ranges from 1 to 30 seconds (default: 3). The value must be a number with a minimum value of 1 and with a maximum value of 30

  • simulated_brightness: Simulate a brightness value. If this device provides a brightness_move_up or brightness_move_down action it is possible to specify the update interval and delta. The action_brightness_delta indicates the delta for each interval. Example:

simulated_brightness:
  delta: 20 # delta per interval, default = 20
  interval: 200 # interval in milliseconds, default = 200

Exposes

Identify (enum)

Initiate device identification. This device is asleep by default.You may need to wake it up first before sending the identify command.. Value will not be published in the state. It's not possible to read (/get) this value. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"identify": NEW_VALUE}. The possible values are: identify.

Battery (numeric)

Remaining battery in %. Value can be found in the published state on the battery property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"battery": ""}. It's not possible to write (/set) this value. The minimal value is 0 and the maximum value is 100. The unit of this value is %.

Action (enum)

Triggered action (e.g. a button click). Value can be found in the published state on the action property. It's not possible to read (/get) or write (/set) this value. The possible values are: on, off, brightness_move_up, brightness_stop.
