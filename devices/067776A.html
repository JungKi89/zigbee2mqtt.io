Legrand 067776A

Model067776A
VendorLegrand
DescriptionNetatmo wired shutter switch with level control (NLLV)
Exposescover (state, position), action, identify, led_in_dark, led_if_on, calibration_mode
Picture

Notes

페어링

구형 펌웨어가 탑재된 장치는 첫 번째 페어링 시도에서 완전히 페어링되지 않을 수 있습니다(Zigbee2MQTT가 인터뷰 성공을 보고한 후에도 LED가 계속 초록색으로 깜빡입니다). 이 경우 #20617의 해결 방법을 따르세요. 이 방법은 장치 초기화, Zigbee2MQTT 재시작, 재페어링을 포함합니다. 신형 펌웨어(펌웨어 빌드 67 및 71에서 테스트됨)를 사용하는 장치는 해결 방법 없이 정상적으로 페어링됩니다. 구형 펌웨어로 페어링한 후에는 OTA 업데이트를 통해 최신 버전으로 업그레이드하는 것을 권장합니다.

Z2M을 사용한 캘리브레이션

Z2M을 사용하여 캘리브레이션을 시작하려면 다음 단계를 수행하세요:

  • 장치가 Z2M 코디네이터에 완전히 조인되었는지 확인합니다(초록색 표시등이 깜빡이지 않고 고정되어야 합니다).
  • Z2M의 장치 'Exposes' 페이지를 사용하여 캘리브레이션 모드(일반적으로 specific_nllv)를 설정합니다. 이미 원하는 캘리브레이션 모드인 경우 up_down_stop으로 전환한 후 몇 초를 기다렸다가 다시 전환합니다.
  • LED가 주황색으로 깜빡이기 시작해야 합니다. 즉시 아무 일도 일어나지 않는 것은 정상입니다. 몇 분 기다리면 장치가 자동으로 커버를 내리고, 몇 분 더 기다리면 다시 올립니다(설정에 따라 다른 캘리브레이션 단계가 수행될 수 있음).
  • 캘리브레이션이 완료되면 LED의 주황색 깜빡임이 멈춥니다(총 최대 5분 소요).

장치에서 직접 캘리브레이션

장치의 위/아래 버튼을 동시에 7초간 눌러 캘리브레이션을 직접 시작할 수 있습니다. LED가 주황색으로 깜빡이기 시작합니다. 셔터가 자동으로 캘리브레이션을 시작하며 여러 번 열고 닫습니다(이 과정은 약 5분 정도 걸립니다). 캘리브레이션 절차 중에는 제품의 어떤 버튼도 누르지 마세요.

베네치안 모드(BSO) 캘리브레이션

venetian_bso 모드(방향 조절 가능한 선쉐이드)의 경우 Legrand의 Home+Control 앱에 설명된 것과 동일한 특수 캘리브레이션 절차를 따라야 합니다. 캘리브레이션할 셔터를 바라봅니다. 이 절차에서 LED는 주황색으로 깜빡여야 합니다. 소요 시간은 약 5분입니다. Z2M에서 venetian_bso 모드를 설정하는 즉시 장치가 주황색으로 깜빡이기 시작하며 다음 단계를 진행할 수 있습니다:

  • 1단계: 스위치의 아래 버튼을 누른 채로 셔터가 반쯤 열렸을 때(50% 열림) 놓습니다. 조금 일찍 또는 늦게 놓아도 다음 단계로 진행합니다.
  • 2단계: 스위치의 아래 버튼을 누른 채로 셔터가 완전히 닫혔을 때 놓습니다.
  • 3단계: 스위치의 위 버튼을 누른 채로 셔터가 완전히 열렸을 때 놓습니다.
  • 4단계: 스위치의 아래 버튼을 누른 채로 셔터가 완전히 닫혔을 때 놓습니다.
  • 5단계: 마지막으로 스위치의 위 버튼을 눌러 셔터 블레이드를 엽니다. 블레이드가 완전히 열리는 즉시 놓습니다.

방향 조절 가능한 선쉐이드 캘리브레이션이 완료되었습니다! 스위치의 버튼을 누른 채로 블레이드 개폐를 제어할 수 있습니다.
틸트 제어: 캘리브레이션 모드를 venetian_bso로 설정한 후 UI에 틸트 제어가 표시되려면 Zigbee2MQTT를 재시작해야 할 수 있습니다.

모델 번호

모델 번호는 국가와 장치 색상에 따라 다릅니다.

  • 프랑스 모델은 Céliane with Netatmo 브랜드로 출시되며, 색상에 따라 다음 번호를 사용합니다: "0 677 26A", "0 677 76A", "0 648 96A".
  • 스페인 모델은 Legrand Valena Next 브랜드로 출시되며, 색상에 따라 다음 번호를 사용합니다: "7 418 07A", "7 418 37A", "7 418 67A".
  • 최근 독일 및 오스트리아 모델은 Legrand Seano with Netatmo 브랜드로 출시되며, 색상에 따라 다음 번호를 사용합니다: "7 656 38", "7 657 38", "7 658 38", "7 659 38".

변형 모델

모델 "0 676 97"의 내부 모듈 변형이 있습니다(스위치가 아님). 이 모델은 버튼이 두 개뿐입니다('설정' 버튼 하나와 버튼을 누른 채로 커버를 올리고 내리는 것 사이를 전환하는 버튼 하나). 별도의 위/아래 버튼이 없기 때문에 이 장치에서 직접 캘리브레이션을 강제하는 방법은 알려져 있지 않습니다(단, Z2M을 사용한 캘리브레이션 방법은 위의 캘리브레이션 섹션을 참조하세요).

OTA updates

This device supports OTA updates, for more information see OTA updates.

Options

How to use device type specific configuration

  • invert_cover: Inverts the cover position, false: open=100,close=0, true: open=0,close=100 (default false). The value must be true or false

  • cover_position_tilt_disable_report: Do not publish set cover target position as a normal 'position' value (default false). The value must be true or false

  • identity_effect: Defines the identification effect to simplify the device identification. Example:

identity_effect:
  effect: blink 3 # allowed: 'blink 3', 'fixed', 'blink green', 'blink blue'
  color: red # allowed: 'default', 'red', 'green', 'blue', 'lightblue', 'yellow', 'pink', 'white'

Exposes

Cover

The current state of this cover is in the published state under the state property (value is OPEN or CLOSE). To control this cover publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"state": "OPEN"}, {"state": "CLOSE"}, {"state": "STOP"}. It's not possible to read (/get) this value. To change the position publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"position": VALUE} where VALUE is a number between 0 and 100.

Action (enum)

Triggered action (e.g. a button click). Value can be found in the published state on the action property. It's not possible to read (/get) or write (/set) this value. The possible values are: identify, open, close, stop, moving, stopped.

Identify (enum)

Blinks the built-in LED to make it easier to identify the device. Value will not be published in the state. It's not possible to read (/get) this value. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"identify": NEW_VALUE}. The possible values are: identify.

Led in dark (binary)

Enables the built-in LED allowing to see the switch in the dark. Value can be found in the published state on the led_in_dark property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"led_in_dark": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"led_in_dark": NEW_VALUE}. If value equals ON led in dark is ON, if OFF OFF.

Led if on (binary)

Enables the LED on activity. Value can be found in the published state on the led_if_on property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"led_if_on": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"led_if_on": NEW_VALUE}. If value equals ON led if on is ON, if OFF OFF.

Calibration mode (enum)

Defines the calibration mode of the switch. (Caution: Changing modes requires a recalibration of the shutter switch!). Value can be found in the published state on the calibration_mode property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"calibration_mode": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"calibration_mode": NEW_VALUE}. The possible values are: classic_nllv, specific_nllv, up_down_stop, temporal, venetian_bso.
