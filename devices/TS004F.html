Tuya TS004F

ModelTS004F
VendorTuya
DescriptionWireless switch with 4 buttons
Exposesoperation_mode, battery, voltage, identify, action
Picture

Notes

중요: 이 노트는 TS004F_1에서 복사되었습니다. 지침 및 동작이 다를 수 있습니다.

배터리

1 × CR2430 (3V)를 사용합니다. 다른 규격(CR2032 등)도 맞을 수 있습니다.

버튼 위치

12
34

페어링

이 리모컨은 다음 모드 중 하나로 사용할 수 있습니다:

  1. Zigbee 네트워크에 페어링 (바인딩 지원: 그룹 하나 제어)

  2. 네트워크 없이 Touchlink를 통해 디바이스 그룹에 바인딩

Zigbee 네트워크 / 공장 초기화

버튼 3을 10초간 눌러 공장 초기화 및 Zigbee 네트워크 참가.
리모컨이 네트워크에 연결될 때까지 모든 LED가 녹색으로 깜박입니다.
페어링 완료에 충분한 배터리가 필요할 수 있습니다.

Touchlink - 네트워크 없음

이 리모컨은 Touchlink를 사용하여 Zigbee 바인딩을 설정하고 코디네이터 없이 사용할 수 있습니다. 다음 단계를 따르세요:

  1. 리모컨이 이전에 네트워크에 연결된 경우, 또는 바인딩을 지우려면 공장 초기화를 수행합니다. 모든 LED가 녹색으로 깜박입니다
  2. 배터리를 제거했다가 다시 삽입하여 "네트워크 참가 모드"를 종료합니다. LED가 깜박임을 멈춥니다
  3. 제어하고 싶지 않은 근처 디바이스의 전원을 끕니다
  4. 버튼 1+3을 6초간 눌러 Touchlink 모드를 활성화합니다. LED 3이 녹색으로 깜박입니다
  5. 리모컨을 대상 디바이스 가까이에 가져가 바인딩을 시작합니다.
    이렇게 하면 대상 디바이스가 해당 네트워크에서 제거되고 리모컨의 숨겨진 Zigbee 네트워크에 추가됩니다
  6. 성공하면 대상 디바이스가 식별되고 리모컨의 LED가 깜박임을 멈춥니다.
    이제 리모컨이 액션 매핑 - 커맨드 모드에 설명된 대로 대상을 직접 제어할 수 있습니다

네트워크 내에서 이 작업을 수행하면 LED가 깜박이더라도 효과가 없습니다.
이 경우 코디네이터를 통해 바인딩을 설정해야 합니다:

바인딩

이 리모컨은 그룹 하나를 직접 제어할 수 있습니다.
개별 디바이스를 직접 제어하는 것은 지원되지 않습니다.

바인딩/언바인딩은 성공한 것처럼 보이지만 실제로는 효과가 없습니다.
대신 다음 단계를 따르세요:

  1. 리모컨을 커맨드 동작 모드로 설정합니다
  2. 제어하려는 그룹에 추가합니다

동작 모드

이 디바이스는 두 가지 모드가 있습니다:

  1. 커맨드 모드 (코디네이터에 7개 액션 전송 + 선택된 그룹 제어)
  2. 이벤트 모드 (코디네이터에 12개 액션 전송)

이벤트 모드는 단일/더블 클릭을 구분하기 위해 약간의 지연이 있습니다.
그러나 여러 번 빠르게 누르면 오작동하여 리모컨이 반응하지 않는 것처럼 느껴집니다.
액션이 큐에 쌓여서 한 번에 1~2개씩 매우 느리게 발생합니다.
메시지는 표준 Zigbee 명령이 아닙니다.

커맨드 모드는 이에 비해 훨씬 반응이 빠릅니다.
액션이 즉시 전송됩니다.
메시지는 표준 Zigbee 명령입니다.

모드 전환 방법:

  • 버튼 2+4를 6초간 누릅니다. LED 3이 한 번 깜박일 때까지
  • 또는 Zigbee2MQTT에서 operation_mode를 설정합니다

  • 해당 LED가 클릭 확인으로 깜박입니다

Options

How to use device type specific configuration

  • identify_timeout: Sets the duration of the identification procedure in seconds (i.e., how long the device would flash).The value ranges from 1 to 30 seconds (default: 3). The value must be a number with a minimum value of 1 and with a maximum value of 30

  • simulated_brightness: Simulate a brightness value. If this device provides a brightness_move_up or brightness_move_down action it is possible to specify the update interval and delta. The action_brightness_delta indicates the delta for each interval. Example:

simulated_brightness:
  delta: 20 # delta per interval, default = 20
  interval: 200 # interval in milliseconds, default = 200

Exposes

Operation mode (enum)

Operation mode: "command" - for group control, "event" - for clicks. Value can be found in the published state on the operation_mode property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"operation_mode": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"operation_mode": NEW_VALUE}. The possible values are: command, event.

Battery (numeric)

Remaining battery in %. Value can be found in the published state on the battery property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"battery": ""}. It's not possible to write (/set) this value. The minimal value is 0 and the maximum value is 100. The unit of this value is %.

Voltage (numeric)

Reported battery voltage in millivolts. Value can be found in the published state on the voltage property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"voltage": ""}. It's not possible to write (/set) this value. The unit of this value is mV.

Identify (enum)

Initiate device identification. This device is asleep by default.You may need to wake it up first before sending the identify command.. Value will not be published in the state. It's not possible to read (/get) this value. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"identify": NEW_VALUE}. The possible values are: identify.

Action (enum)

Triggered action (e.g. a button click). Value can be found in the published state on the action property. It's not possible to read (/get) or write (/set) this value. The possible values are: on, off, brightness_step_up, brightness_step_down, brightness_move_up, brightness_move_down, color_temperature_step_up, color_temperature_step_down, brightness_stop, 1_single, 1_double, 1_hold, 2_single, 2_double, 2_hold, 3_single, 3_double, 3_hold, 4_single, 4_double, 4_hold.
