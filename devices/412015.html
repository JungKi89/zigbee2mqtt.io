VendorLegrand
DescriptionDIN power consumption module
Exposespower, power_apparent, power_alarm_active, power_alarm

Notes

모델 번호

Legrand에서는 모델 번호가 국가 및 기기 색상에 따라 다릅니다. 예를 들면:

  • 프랑스 모델은 Céliane with Netatmo 브랜드로, 스페인 모델은 Legrand Valena Next 브랜드로 판매됩니다. 단, 이 기기는 색상 옵션이 없어 모델이 하나뿐입니다: "412015" 또는 "4 120 15"

국가별 브랜드명:

  • Céliane™ with Netatmo 판매 지역 → France and Overseas territories, Greece, Poland, Hungary, Tunisia, Morocco, Ivory Coast, Czech Republic, Russia, Mauritius
  • Dooxie™ with Netatmo 판매 지역 → France and Overseas territories
  • Mosaic™ with Netatmo 판매 지역 → France and Overseas territories, Ivory Coast
  • Living Now™ with Netatmo 판매 지역 → Italy, Belgium, Greece, Portugal, Lebanon, Israel, Chile, Peru, Mexico
  • Valena Allure™ with Netatmo 판매 지역 → Greece, Germany, Austria, Poland, Slovakia, Bulgaria, Czech Republic, Hungary, Russia
  • Valena Life™ with Netatmo 판매 지역 → Greece, Germany, Austria, Portugal, Poland, Slovakia, Bulgaria, Czech Republic, Hungary, Lituania, Russia
  • Valena Next™ with Netatmo 판매 지역 → Spain, Belgium
  • Arteor™ with Netatmo 판매 지역 → Australia, New Zealand, India, Malaysia, Lebanon, Mauritius, South Africa
  • Plexo™ with Netatmo 판매 지역 → France and Overseas territories, Spain, Belgium
  • Modul'Up™ with Netatmo 판매 지역 → France and Overseas territories

전력 강제 읽기

  • power: 기기에 현재 유효 전력을 요청합니다.

유효 전력을 요청하는 MQTT 메시지 페이로드 예시. zigbee2mqtt/FRIENDLY_NAME/get으로 전송하세요:

{
    "power"
}

전력 알람 설정

  • power_alarm: 전력 알람을 활성화하거나 비활성화하고 값을 설정합니다: DISABLE (기본값) / integer (kWh 단위)

전력 알람을 비활성화하는 MQTT 메시지 페이로드 예시. zigbee2mqtt/FRIENDLY_NAME/set으로 전송하세요:

{
    "power_alarm": "DISABLE"
}

3.3 kWh에서 전력 알람을 활성화하는 MQTT 메시지 페이로드 예시. zigbee2mqtt/FRIENDLY_NAME/set으로 전송하세요:

{
    "power_alarm": "3300"
}

해당 값에 도달하면 power_alarm_active binary_sensor가 true로 변경됩니다.

식별

LED를 사용하여 기기를 식별하는 데 도움이 됩니다.

  • identify['effect']: effect에서 blink3 & fixed에서만 작동합니다. 값:

    • blink3
    • fixed
    • blinkgreen
    • blinkblue

  • identify['color']: effect에서 blink3 & fixed에서만 작동합니다. 값:

    • default
    • red
    • green
    • blue
    • lightblue
    • yellow
    • pink
    • white

기기를 식별하는 MQTT 메시지 페이로드 예시. zigbee2mqtt/FRIENDLY_NAME/set으로 전송하세요:

{
    "identify": {
    "effect": "blink3",
    "color": "white"
    }
}

OTA updates

This device supports OTA updates, for more information see OTA updates.

Options

How to use device type specific configuration

  • power_calibration: Calibrates the power value (percentual offset), takes into effect on next report of device. The value must be a number.

  • power_precision: Number of digits after decimal point for power, takes into effect on next report of device. This option can only decrease the precision, not increase it. The value must be a number with a minimum value of 0 and with a maximum value of 3

  • identity_effect: Defines the identification effect to simplify the device identification. Example:

identity_effect:
  effect: blink 3 # allowed: 'blink 3', 'fixed', 'blink green', 'blink blue'
  color: red # allowed: 'default', 'red', 'green', 'blue', 'lightblue', 'yellow', 'pink', 'white'

Exposes

Power (numeric)

Instantaneous measured power. Value can be found in the published state on the power property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"power": ""}. It's not possible to write (/set) this value. The unit of this value is W.

Power apparent (numeric)

Instantaneous measured apparent power. Value can be found in the published state on the power_apparent property. It's not possible to read (/get) or write (/set) this value. The unit of this value is VA.

Power alarm active (binary)

Value can be found in the published state on the power_alarm_active property. It's not possible to read (/get) or write (/set) this value. If value equals true power alarm active is ON, if false OFF.

Power alarm (binary)

Enable/disable the power alarm. Value can be found in the published state on the power_alarm property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"power_alarm": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"power_alarm": NEW_VALUE}. If value equals true power alarm is ON, if false OFF.
