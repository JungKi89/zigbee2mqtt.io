IKEA E2489

ModelE2489
VendorIKEA
DescriptionBILRESA remote control with buttons (Matter)
Exposesbattery, voltage, identify, action
Picture

Unofficial support

This device is part of the IKEA Matter/Thread line-up.
The hidden Zigbee mode is not officially supported by IKEA. It exists mainly to keep backwards compatibility via Touchlink.
As a result, the Zigbee firmware is stripped-down to the essentials, and could even be removed in OTA updates.

Notes

관련 기기

BILRESA 스크롤 휠

배터리

AAA 배터리 2개 사용.
알칼라인 배터리(1.5V) 사용 시 잔량 비율이 정확하게 보고됩니다.

이 기기는 사용하지 않을 때 에너지 절약을 위해 슬립 상태가 됩니다.
슬립 상태에서는 Z2M 명령에 응답하지 않습니다.
버튼을 눌러 기기를 깨운 후 조작하세요.

페어링

리모컨을 페어링하려면 다음 순서를 따르세요:

  1. 페이스플레이트 / 배터리 커버를 제거하여 중앙에 있는 페어링 버튼을 찾으세요
  2. 페어링 버튼을 ~10초 동안 눌러 리모컨을 초기화하세요. 누르는 동안 빨간 LED가 깜빡입니다.
    호박색 LED가 맥동할 때 놓으세요. 리모컨이 이제 Thread 페어링 모드로 진입합니다
  3. 리모컨을 다른 기기들에서 멀리 이동하세요.
    페어링 버튼을 4번 눌러 Touchlink를 활성화하세요. 호박색 LED가 빠르게 깜빡입니다.
    리모컨이 이제 주변 기기에 바인딩을 시도합니다
  4. 페어링 버튼을 8번 누르세요. LED가 계속 꺼진 상태입니다!
    리모컨이 이제 Zigbee 페어링 모드로 진입합니다

코디네이터를 통해 페어링하는 것이 중요합니다!
'불량' 라우터(예: Telink Tuya, AwoX)를 통한 페어링은 버튼이 작동하지 않을 수 있습니다.

최신 버전으로 업데이트된 코디네이터가 필요할 수 있습니다.

바인딩

E2489 모델, v1.8.5에서 테스트:
모든 리모컨은 그룹 21658을 직접 제어합니다. 다른 것과 언바인딩하거나 바인딩할 수 없습니다.

  • 네트워크 내부에서는 대상 기기를 그룹 21658에 추가하여 페어링할 수 있습니다.

    • 대상 기기에 대한 리포팅을 수동으로 설정해야 합니다
    • 바인딩/언바인딩은 성공한 것처럼 보이지만 실제 효과가 없습니다
    • Z2M이 모르는 상태에서 기기가 그룹 안에 있을 수 있습니다.
      Z2M UI에서 그룹에 먼저 추가한 후 나중에 제거할 수 있습니다

  • 네트워크 외부에서는 Touchlink를 통한 페어링이 가능합니다

    • 대상 기기에 매우 가까이 놓으세요 (충돌 기기는 전원 차단)
    • 페어링에서 설명한 대로 Touchlink를 활성화하세요. (초기화 불필요)
    • 리모컨 복제는 알 수 없음 / 불가 (적어도 오래된 리모컨에서는)
    • 리모컨이 네트워크 외부에 있는 경우 Touchlink 활성화 시:
      • 대상 기기가 해당 네트워크에서 제거됩니다
      • 기기들이 바인딩됩니다
    • 리모컨과 대상 기기가 모두 네트워크 내부에 있는 경우 Touchlink 활성화 시:
      • 대상이 그룹 21658에 추가됩니다
      • 다른 그룹에서 제거되지 않습니다

ON 한 번 누르기onOn
ON 두 번 누르기on_doubleTradfriArrowSingle (256,13)
ON 세 번 이상 누르기nothingnothing
ON 길게 누르기, (누름 + 떼기)brightness_move_up + brightness_stopMove (Up, 83) + StopWithOnOff
OFF 한 번 누르기offOff
OFF 두 번 누르기off_doubleTradfriArrowSingle (257,13)
OFF 세 번 이상 누르기nothingnothing
OFF 길게 누르기, (누름 + 떼기)brightness_move_down + brightness_stopMove (Down, 83) + StopWithOnOff
  • 명령은 즉시 전송되지 않습니다!
    • 모든 액션에 1초의 지연이 있습니다.
      (단일 및 이중 누르기를 구분하기 위해 필요)
    • 이전 SOMRIG와 달리 initial_press를 전송하지 않습니다
  • 세 번 누르기 이상은 구현할 방법이 없습니다.
    리모컨이 메시지를 전송하지 않으므로 Z2M이나 자동화가 감지할 수 없습니다

씬

리모컨은 씬을 순환하기 위해 사용자 정의 IKEA 명령을 전송합니다.

명령:

  • *TradfriArrowSingle (256,13)*은 그룹 65289에서 다음 씬을 호출합니다
  • *TradfriArrowSingle (257,13)*은 그룹 65289에서 이전 씬을 호출합니다

호환성:

  • IKEA WS Matter 전구 (2026)는 작동하며 씬이 없으면 8개의 씬을 생성합니다
    • 기본 씬은 색온도만 저장합니다: 0-5 중립-차가운, 6,7,0 중립-따뜻한
  • v3.x.x (2024) IKEA WS 전구는 작동하며 씬이 없으면 3개의 씬을 생성합니다
    • 기본 씬은 색온도만 저장합니다: 0 중립, 1 차가운, 2 따뜻한
  • v2.x.x (2019) IKEA WS 전구는 작동하지만 씬을 수동으로 추가해야 할 수 있습니다
  • v1.x.x (201x) IKEA WS 전구는 명령을 전혀 인식하지 못할 수 있습니다
  • 다른 브랜드는 IKEA 명령을 인식하지 못합니다!

씬 추가/편집:

  1. IKEA 전구를 그룹 65289에 추가하세요
  2. 그룹에 씬을 생성하여 덮어쓰거나 새로 추가하세요

펌웨어

  • 초기 출하 제품에는 v1.8.5 (20250206)이 사전 설치되어 있습니다
  • 업데이트는 Matter를 통해 제공됩니다.
    업데이트를 위해 Thread 허브로 기기를 이동하세요
  • 사용 가능한 버전은 여기에서 확인하세요 (BILRESA 또는 4476 검색)

문제 해결

  1. 액션이 N/A로 보고되거나 페어링 어려움
    • 최신 버전으로 업데이트된 코디네이터를 사용하세요
    • '불량' 라우터(예: Telink Tuya, AwoX)의 전원을 차단하고 다시 페어링하세요
    • 코디네이터를 통해 직접 페어링하세요
    • 동글 코디네이터에 USB 2.0 연장 케이블을 추가하세요
    • 충전식 배터리를 사용하세요
  2. 액션은 작동하지만 배터리가 N/A로 보고됨
    • 리모컨을 재부팅하고 잔량을 새로고침하세요
    • 그 외에는 1번과 동일
  3. 기기가 Z2M 요청에 응답하지 않음
    • 버튼을 눌러 기기를 깨우세요

Options

How to use device type specific configuration

  • identify_timeout: Sets the duration of the identification procedure in seconds (i.e., how long the device would flash).The value ranges from 1 to 30 seconds (default: 3). The value must be a number with a minimum value of 1 and with a maximum value of 30

  • simulated_brightness: Simulate a brightness value. If this device provides a brightness_move_up or brightness_move_down action it is possible to specify the update interval and delta. The action_brightness_delta indicates the delta for each interval. Example:

simulated_brightness:
  delta: 20 # delta per interval, default = 20
  interval: 200 # interval in milliseconds, default = 200

Exposes

Battery (numeric)

Remaining battery in %. Value can be found in the published state on the battery property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"battery": ""}. It's not possible to write (/set) this value. The minimal value is 0 and the maximum value is 100. The unit of this value is %.

Voltage (numeric)

Reported battery voltage in millivolts. Value can be found in the published state on the voltage property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"voltage": ""}. It's not possible to write (/set) this value. The unit of this value is mV.

Identify (enum)

Initiate device identification. This device is asleep by default.You may need to wake it up first before sending the identify command.. Value will not be published in the state. It's not possible to read (/get) this value. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"identify": NEW_VALUE}. The possible values are: identify.

Action (enum)

Triggered action (e.g. a button click). Value can be found in the published state on the action property. It's not possible to read (/get) or write (/set) this value. The possible values are: on, off, brightness_move_up, brightness_move_down, brightness_stop, off_double, on_double.
