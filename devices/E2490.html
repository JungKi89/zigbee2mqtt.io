IKEA E2490

ModelE2490
VendorIKEA
DescriptionBILRESA remote control with scroll wheel (Matter)
Exposesbattery, voltage, identify, action
Picture

Unofficial support

This device is part of the IKEA Matter/Thread line-up.
The hidden Zigbee mode is not officially supported by IKEA. It exists mainly to keep backwards compatibility via Touchlink.
As a result, the Zigbee firmware is stripped-down to the essentials, and could even be removed in OTA updates.

Notes

관련 기기

BILRESA 듀얼 버튼

정보

  • FCC - emissions and teardown
  • CSA IoT - Matter compliance
  • CSA IoT - Zigbee compliance
  • Based on Qorvo chipset

알려진 문제

  • 낮은 클릭 감도: 버튼을 가볍게 누르면 딸깍 소리가 나지만 실제로 입력이 등록되지 않을 수 있습니다. 버튼을 확실히 눌러 이벤트가 발생하도록 하세요.

  • 부분적이고 충돌하는 바인딩 지원: 모든 리모컨이 동일한 기기를 제어합니다! 바인딩 참조

  • 느린 액션, 동기화되지 않는 On/Off 명령, 잘못된 형식의 MoveToLevel 명령: 액션 매핑 참조

배터리

AAA 배터리 2개 사용.
잔량 백분율은 알카라인 배터리(1.5V) 기준으로 맞춰진 것으로 보입니다.

이 기기는 사용하지 않을 때 절전 모드로 전환됩니다.
절전 중에는 Zigbee2MQTT 명령에 응답하지 않습니다.
버튼을 눌러 기기를 깨운 후 조작하세요.

페어링

배터리 커버를 열면 페어링 버튼을 찾을 수 있습니다.

리모컨은 다음 중 하나의 모드로 사용할 수 있습니다:

  1. Matter/Thread 네트워크에 페어링
    (바인딩 지원 없음)

  2. Zigbee 네트워크에 페어링
    (부분적 바인딩 지원: 모든 BILRESA 리모컨이 동일한 1~3개 그룹을 제어)

  3. 네트워크 없이 Touchlink를 통해 1~3개 기기 그룹에 직접 바인딩

공장 초기화

페어링 버튼을 약 10초 동안 길게 눌러 공장 초기화를 수행합니다. 누르는 동안 LED가 빨간색으로 깜박입니다.
LED가 주황색으로 맥동할 때 손을 뗍니다. 리모컨이 Matter/Thread 페어링 모드로 진입합니다.

Matter

공장 초기화 후 기기는 자동으로 Matter/Thread 페어링 모드로 진입합니다.
페어링 버튼을 한 번 누르면 Matter 모드로 전환됩니다.

Zigbee

이 기기는 최신 코디네이터를 통해 직접 페어링하는 것이 중요합니다.
구버전이나 불량 라우터*(예: Telink Tuya, AwoX)*를 통해 페어링하면 문제가 발생할 수 있습니다.
또한 v9.0.0 프리릴리스 Silabs 펌웨어에서는 페어링이 불가능하다는 보고도 있습니다.

Zigbee 네트워크에 페어링하려면 아래 순서를 따라야 합니다. 모든 단계가 필요합니다:

  1. 리모컨을 공장 초기화합니다
  2. 리모컨을 다른 기기와 멀리 두거나 전원을 끕니다
  3. Touchlink 모드에 진입하되, 주변 기기에 바로 페어링하지 않습니다
  4. Touchlink 모드에서 페어링 버튼을 8번 눌러 Zigbee 네트워크에 참가합니다.
    LED가 꺼지며, Zigbee 페어링 모드임을 나타내는 시각적 표시는 없습니다.

Touchlink

이 리모컨은 Touchlink를 사용하여 Zigbee 바인딩을 설정합니다. 네트워크 내외 모두에서 동작합니다. 다음 단계를 따르세요:

  1. 선택적으로 리모컨을 공장 초기화합니다 (네트워크를 떠나고 바인딩을 초기화)
  2. 제어하고 싶지 않은 주변 기기의 전원을 끕니다
  3. 페어링 버튼을 4번 눌러 Touchlink 모드를 활성화합니다
  4. 첫 번째 LED가 주황색으로 빠르게 깜박이며, 채널 1을 나타냅니다.
    전면 하단 버튼을 눌러 바인딩할 채널을 선택합니다.
    채널 2는 채널 1 바인딩 성공 후 활성화됩니다. 채널 3은 채널 2 성공 후 활성화됩니다.
    동일한 기기에 여러 채널을 바인딩하거나, 하나의 채널에 여러 기기를 추가할 수 있습니다.
  5. 리모컨을 대상 기기 가까이 가져다 대어 바인딩을 시작합니다
    • 리모컨이 네트워크에 연결되지 않은 경우: 대상 기기를 해당 네트워크에서 제거하고 리모컨의 숨겨진 Zigbee 네트워크에 추가합니다
    • 리모컨은 네트워크에 연결되어 있고 대상은 연결되지 않은 경우: 대상이 식별을 수행하지만 아무 일도 일어나지 않습니다
    • 리모컨과 대상이 동일한 네트워크에 연결된 경우: 선택한 채널에 해당하는 그룹(21658-21660)에 대상 기기를 추가합니다
  6. 성공하면 대상 기기가 식별을 수행하고 리모컨 LED가 깜박임을 멈춥니다.
    이제 리모컨이 액션 매핑에 설명된 대로 대상을 직접 제어합니다

Touchlink를 통한 리모컨 복제는 테스트했으나 성공하지 못했습니다.

바인딩

모델 E2490, v1.8.5(초기 펌웨어) 기준으로 테스트:

모든 리모컨은 그룹 21658, 21659, 21660 *(채널 1-3)*을 직접 제어합니다. 그룹 21658은 BILRESA 듀얼 버튼과도 충돌합니다!
다른 것으로 바인딩/언바인딩할 수 없습니다(코디네이터의 바인딩 요청은 성공한 것처럼 보이지만 효과가 없습니다).
즉, 네트워크에 여러 리모컨이 있을 경우 각 리모컨을 서로 다른 기기/그룹에 페어링할 수 없습니다. 모든 리모컨이 서로의 대상을 제어하게 됩니다. 해결책은 자동화를 사용하는 것입니다.

기기를 직접 제어하려면 Touchlink 단계를 따르세요. 그러면 3개의 채널이 활성화되고 대상 기기가 각 그룹에 추가됩니다.
3개의 채널을 활성화한 후에는 Zigbee2MQTT에서 그룹을 생성하고 제어하려는 기기를 추가/제거할 수 있습니다(Touchlink 단계를 건너뛰고).

Zigbee2MQTT는 리모컨이 그룹을 제어한다는 사실을 인식하지 못합니다. 따라서 실제 상태를 가상 상태와 동기화하려면 대상 기기의 보고(reporting)를 추가로 설정해야 합니다.

Rotatewheeln × brightness_move_to_leveln × MoveToLevel (0→255 brightness, 1s transition)
SinglebottomnothingCycle bound groups (21658→21660)

  • Long-pressing the wheel is confirmed to generate no Zigbee events

  • The remote alternates between On and Off commands instead of sending Toggle

    • Current on/off states are stored on the remote - one for each channel
    • Benefit: all group members stay in sync with each other, instead of toggling individually
      (i.e. Prevents light1 on, light2 off)
    • Downside: controlling the group from Zigbee2MQTT will get it out-of-sync
      (e.g. Remote sends Off when group is already Off)

  • The remote sends multiple MoveToLevel commands while rotating the wheel

    • Current brightness value is stored on the remote. The same value is used for all channels
    • Rotate clockwise to increase, counter-clockwise to decrease
    • The command is malformed, it's missing 2 parameters (option mask and override). And level 255 might be undefined. For lights, the maximum is 254.

  • Bottom button works only after the remote activated Touchlink on multiple channels

  • If the channels are unlocked, one LED lights up on every press to indicate the active channel

  • Clicks are not sent instantly

    • A ~0.5s delay is built-in to decide between multi-presses
    • It doesn't send any initial_press like the older SOMRIG does

Scenes

The remote sends custom IKEA commands to cycle between scenes.

Commands:

  • TradfriArrowSingle (256,13) recalls next scene in group 65289
  • TradfriArrowSingle (257,13) recalls previous scene in group 65289

Compatibility:

  • IKEA WS Matter bulbs (2026) work and will create 8 scenes if there aren't any
    • Default scenes store only color temp: 0-5 neutral-cold, 6,7,0 neutral-warm
  • IKEA WS bulbs on v3.x.x (2024) work, and will create 3 scenes if there aren't any
    • Default scenes store only color temp: 0 neutral, 1 cold, 2 warm
  • IKEA WS bulbs on v2.x.x (2019) work, but may need adding scenes manually
  • IKEA WS bulbs on v1.x.x (201x) might not know the commands at all
  • Other brands won't recognize the IKEA commands!

Add / Edit scenes:

  1. Add IKEA bulbs to group 65289
  2. Create scenes in the group to overwrite them or add new ones

Firmware

  • Initial batches come with v1.8.5 (20250226) preinstalled
  • Updates are provided over Matter.
    Move the device to a Thread hub to update
  • See the available versions here (search BILRESA or 4476)

Options

How to use device type specific configuration

  • identify_timeout: Sets the duration of the identification procedure in seconds (i.e., how long the device would flash).The value ranges from 1 to 30 seconds (default: 3). The value must be a number with a minimum value of 1 and with a maximum value of 30

  • simulated_brightness: Simulate a brightness value. If this device provides a brightness_move_up or brightness_move_down action it is possible to specify the update interval and delta. The action_brightness_delta indicates the delta for each interval. Example:

simulated_brightness:
  delta: 20 # delta per interval, default = 20
  interval: 200 # interval in milliseconds, default = 200

Exposes

Battery (numeric)

Remaining battery in %. Value can be found in the published state on the battery property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"battery": ""}. It's not possible to write (/set) this value. The minimal value is 0 and the maximum value is 100. The unit of this value is %.

Voltage (numeric)

Reported battery voltage in millivolts. Value can be found in the published state on the voltage property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"voltage": ""}. It's not possible to write (/set) this value. The unit of this value is mV.

Identify (enum)

Initiate device identification. This device is asleep by default.You may need to wake it up first before sending the identify command.. Value will not be published in the state. It's not possible to read (/get) this value. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"identify": NEW_VALUE}. The possible values are: identify.

Action (enum)

Triggered action (e.g. a button click). Value can be found in the published state on the action property. It's not possible to read (/get) or write (/set) this value. The possible values are: on, off, brightness_move_to_level, off_double, on_double.
