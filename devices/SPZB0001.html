Eurotronic SPZB0001

ModelSPZB0001
VendorEurotronic
DescriptionSpirit Zigbee wireless heater thermostat
Exposesbattery, child_lock, climate (occupied_heating_setpoint, current_heating_setpoint, local_temperature, system_mode, running_state, local_temperature_calibration, pi_heating_demand), trv_mode, valve_position, mirror_display
Picture

Notes

페어링

페어링에 문제가 있으면 디바이스를 초기화하세요.

  • 디바이스가 자동 또는 난방 모드(꺼짐 아님)인지 확인합니다. boost, +, - 버튼을 동시에 누릅니다(화면에 1~10의 카운트가 표시되며, 이 작업이 동작하려면 온도조절기를 라디에이터 밸브에서 분리해야 할 수 있습니다).
  • ‘rES’가 표시되면 버튼을 놓습니다.
  • ‘Jin’이 표시된 후 boost 버튼을 한 번 눌러 Zigbee 네트워크 페어링을 시작합니다.
  • 페어링에 성공하면 ‘Ins’가 표시되고 boost 버튼이 녹색으로 깜박여야 합니다. boost 버튼을 다시 누르기 전에 온도조절기가 라디에이터 밸브에 장착되어 있는지 확인하세요.
  • 이제 화면에 ‘Ada’가 표시되어 온도조절기를 밸브에 기계적으로 보정하는 적응 과정이 시작되었음을 나타냅니다.

권장 사항

이 디바이스는 짧은 시간 내에 동일한 페이로드로 여러 메시지를 전송합니다. 고유한 액션 페이로드를 잃지 않고 이를 제한하기 위해 debounce 옵션을 설정하는 것이 좋습니다.

예시 (devices.yaml)

‘0xabc457fffe679xyz’:
    friendly_name: my_device
    debounce: 0.5

제어

현재 난방 설정 온도

{
    "current_heating_setpoint": 21.5
}

점유 또는 비점유 난방 설정 온도를 설정할 때도 현재 난방 설정 온도가 변경됩니다.

시스템 모드

시스템 모드는 off, auto, 또는 heat 중 하나입니다. heat로 설정하면 boost 호스트 플래그가 설정되고, off를 사용하면 window_open 호스트 플래그가 설정됩니다(화면에 off가 표시됩니다).

Eurotronic 호스트 플래그

eurotronic_host_flags 속성에는 각 호스트 옵션에 대한 true/false 필드가 포함된 객체가 있습니다.

{
  "eurotronic_host_flags": {
    "mirror_display": false,
    "boost": false,
    "window_open": false,
    "child_protection": true
  }
}

eurotronic_host_flags가 포함된 메시지를 set MQTT 토픽에 발행하여 이 플래그를 전환할 수 있습니다. 예: 화면 미러링 활성화:

{"eurotronic_host_flags": {"mirror_display": true}}

true 또는 false에는 따옴표가 없습니다!

Eurotronic 시스템 모드

이 기능은 eurotronic_host_flags를 위해 더 이상 사용되지 않지만, 현재는 여전히 작동합니다.

이것은 여러 디바이스별 기능을 설정하는 비트맵 인코딩 필드입니다. 단일 비트를 설정하는 것은 불가능하며 항상 전체 비트맵이 쓰입니다. 비트 0은 쓰기가 불가능한 것으로 보이며 항상 설정된 것으로 보고되므로 기록한 값 + 1이 보고될 것을 예상하세요.

비트위치
0알 수 없음 (기본값 1)
1화면 미러
2Boost
3알 수 없음
4창문 열림 비활성화
5창문 열림 설정 (창문 열림 비활성화로 보고됨)
6알 수 없음
7어린이 보호

eurotronic_system_mode 예시:

화면 미러, 3으로 보고됨

{
    "eurotronic_system_mode": 2
}

외부 창문 열림 신호, current_heating_setpoint가 "5"로 보고되고 디바이스 화면에 "OFF"가 표시됨

{
    "eurotronic_system_mode": 32
}

외부 창문 닫힘 신호, 마지막 current_heating_setpoint 값이 복원됨

{
    "eurotronic_system_mode": 16
}

화면 미러 및 어린이 보호 설정.

{
    "eurotronic_system_mode": 66
}

Eurotronic 오류 상태

{
    "eurotronic_error_status": 0
}

이 필드는 읽기 전용 비트맵입니다.

비트위치
0예약됨
1예약됨
2예약됨
3밸브 적응 실패 (E1)
4밸브 움직임이 너무 느림 (E2)
5밸브 움직이지 않음/차단됨 (E3)
6예약됨
7예약됨

OTA updates

This device supports OTA updates, for more information see OTA updates.

Options

How to use device type specific configuration

  • thermostat_unit: Controls the temperature unit of the thermostat (default celsius). The value must be one of celsius, fahrenheit

Exposes

Battery (numeric)

Remaining battery in %, can take up to 24 hours before reported. Value can be found in the published state on the battery property. It's not possible to read (/get) or write (/set) this value. The minimal value is 0 and the maximum value is 100. The unit of this value is %.

Child lock (binary)

Enables/disables physical input on the device. Value can be found in the published state on the child_lock property. It's not possible to read (/get) this value. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"child_lock": NEW_VALUE}. If value equals LOCK child lock is ON, if UNLOCK OFF.

Climate

This climate device supports the following features: occupied_heating_setpoint, current_heating_setpoint, local_temperature, system_mode, running_state, local_temperature_calibration, pi_heating_demand.

  • occupied_heating_setpoint: Temperature setpoint. To control publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"occupied_heating_setpoint": VALUE} where VALUE is the °C between 5 and 30. To read send a message to zigbee2mqtt/FRIENDLY_NAME/get with payload {"occupied_heating_setpoint": ""}.
  • current_heating_setpoint: Temperature setpoint. To control publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"current_heating_setpoint": VALUE} where VALUE is the °C between 5 and 30. To read send a message to zigbee2mqtt/FRIENDLY_NAME/get with payload {"current_heating_setpoint": ""}.
  • pi_heating_demand: Position of the valve (= demanded heat) where 0% is fully closed and 100% is fully open. Writing (/set) this attribute is not possible. Reading (/get) this attribute is not possible.
  • local_temperature: Current temperature measured on the device (in °C). To read send a message to zigbee2mqtt/FRIENDLY_NAME/get with payload {"local_temperature": ""}.
  • system_mode: Mode of this device. To control publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"system_mode": VALUE} where VALUE is one of: off, auto, heat. To read send a message to zigbee2mqtt/FRIENDLY_NAME/get with payload {"system_mode": ""}.
  • running_state: The current running state. Possible values are: idle, heat. To read send a message to zigbee2mqtt/FRIENDLY_NAME/get with payload {"running_state": ""}.
  • local_temperature_calibration: Offset to add/subtract to the local temperature. To control publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"local_temperature_calibration": VALUE}.To read send a message to zigbee2mqtt/FRIENDLY_NAME/get with payload {"local_temperature": ""}.The minimal value is -2.5 and the maximum value is 2.5 with a step size of 0.1.

Trv mode (enum)

Select between direct control of the valve via the valve_position or automatic control of the valve based on the current_heating_setpoint. For manual control set the value to 1, for automatic control set the value to 2 (the default). When switched to manual mode the display shows a value from 0 (valve closed) to 100 (valve fully open) and the buttons on the device are disabled.. Value can be found in the published state on the trv_mode property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"trv_mode": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"trv_mode": NEW_VALUE}. The possible values are: 1, 2.

Valve position (numeric)

Directly control the radiator valve when trv_mode is set to 1. The values range from 0 (valve closed) to 255 (valve fully open). Value can be found in the published state on the valve_position property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"valve_position": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"valve_position": NEW_VALUE}. The minimal value is 0 and the maximum value is 255.

Mirror display (binary)

Mirror display of the thermostat. Useful when it is mounted in a way where the display is presented upside down.. Value can be found in the published state on the mirror_display property. To read (/get) the value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/get with payload {"mirror_display": ""}. To write (/set) a value publish a message to topic zigbee2mqtt/FRIENDLY_NAME/set with payload {"mirror_display": NEW_VALUE}. If value equals ON mirror display is ON, if OFF OFF.
